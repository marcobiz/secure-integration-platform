# Technical release candidate `0.1.0-alpha.1`

This document describes a private-preview technical candidate. It is not a public
release, is not production-ready, and does not authorize a tag, a GitHub Release or any
NuGet, npm or container-registry publication. The future tag name is
`v0.1.0-alpha.1`, but creating it is outside this candidate.

## Version identity

- product, .NET package/assembly informational version, Admin package, OpenAPI and OCI
  version label: `0.1.0-alpha.1`;
- inbound protocol version: `1.0`, unchanged;
- canonical `sample-secure-service` Connector version: `1.0.0`, unchanged;
- OCI revision label: the exact 40-character Git commit recorded by `manifest.json`.

`Directory.Build.props` is the canonical product-version source. The artifact writer
fails closed when Admin, OpenAPI, package, manifest or OCI metadata differs from it.

## Candidate contents

`eng/Build-AlphaReleaseArtifacts.ps1` writes only outside the repository and produces:

- the one already packable Core alpha package, `SecureIntegration.Broker.Sdk`;
- Gateway and migrations OCI image archives with version/revision labels;
- the Admin static build archive;
- the allowlisted Core source archive;
- SPDX SBOM documents for application, Admin and both candidate images;
- a redacted release manifest, its SHA-256 sidecar and `SHA256SUMS`.

The Core export keeps its raw manifest SHA-256 as run-specific evidence because
`generatedAtUtc` remains present. `normalizedInventorySha256` is a separate identity over
the exact source commit, ordinal `/`-normalized paths, byte counts and per-file SHA-256
values. Its canonical payload is UTF-8 without BOM and excludes timestamps and other
run-specific fields.

## Qualification and known limits

Two independent clean-clone builds must use empty output directories. Qualification
checks the same normalized Core inventory digest and file inventory, final checksums,
package allowlist and clean consumer install, OCI labels/non-root/read-only/health,
candidate-image golden path, secret/evidence exclusion and complete cleanup. Archive
bytes are not required to be bit-for-bit reproducible.

The private-preview limits remain:

- Direct sample key material is process-local and not production-grade;
- APIs are unstable and the only supported evaluation path is the documented synthetic
  Direct .NET golden path;
- no Azure/cloud qualification, FSE2 live qualification, notarization or real signing is
  claimed;
- `Proprietary`/`UNLICENSED` metadata is intentionally unchanged. NuGet warning
  `NU5124` is suppressed only by the local candidate writer; a human license decision
  and authorized distribution metadata remain blockers to public publication;
- `PUBLIC_RELEASE_GO = NO` and `PRODUCTION_READY = NO`.

`NONDETERMINISTIC_UI_MOCK_20_AXE_SNAPSHOT` is a known non-blocking follow-up. This
candidate does not change UI code, CSS, UI tests or Axe thresholds.
