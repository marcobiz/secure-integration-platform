# `v0.1.0-alpha.1` — PUBLIC TECHNICAL PREVIEW

This is the release-note candidate for the intended GitHub public prerelease `v0.1.0-alpha.1`. The software is an alpha technical preview: it is **not production-ready**, carries no SLA, and makes no certification, accreditation, enterprise-support, high-availability, disaster-recovery, API-stability, artifact-signing, provenance, or absolute binary-reproducibility claim. This governance pull request does not create the tag or GitHub Release and does not publish a NuGet package or container image.

## Supported evaluation path

The only supported golden path is:

```text
Direct .NET → Gateway → Published REST Connector → Synthetic Provider → mock HTTPS/mTLS
```

The quickstart starts PostgreSQL 18, migrations, Gateway, same-origin Admin Web, the Synthetic Provider, and a mock HTTPS/mTLS service locally. It requires Docker, the pinned .NET SDK, Node/npm for applicable source validation, and PowerShell; it requires no cloud account. Follow [`docs/operations/ALPHA-GOLDEN-PATH.md`](../operations/ALPHA-GOLDEN-PATH.md). APIs, contracts, and the SDK remain alpha and may change incompatibly in later previews. The Direct sample's process-local key handling is evaluation-only, not production key custody.
