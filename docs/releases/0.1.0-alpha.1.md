Secure Integration Platform `v0.1.0-alpha.1` was published on 24 August 2026 as a

binary-reproducibility claim. Publication did not publish the NuGet package to NuGet.org
or either container image to a registry.

## Supported evaluation path

The only supported golden path is:

```text
Direct .NET → Gateway → Published REST Connector → Synthetic Provider → mock HTTPS/mTLS
```

The quickstart starts PostgreSQL 18, migrations, Gateway, same-origin Admin Web, the
Synthetic Provider, and a mock HTTPS/mTLS service locally. It requires Docker, the pinned
.NET SDK, Node/npm for applicable source validation, and PowerShell; it requires no cloud
account. Follow the
[alpha golden-path runbook at the released commit](https://github.com/marcobiz/secure-integration-platform/blob/ee3072be5e34a7b0477907a2580dcf454b8a4aba/docs/operations/ALPHA-GOLDEN-PATH.md).
APIs, contracts, and the SDK remain alpha and may change incompatibly in later previews.
The Direct sample's process-local key handling is evaluation-only, not production key
custody.

## Verification and manifest errata

`SHA256SUMS` binds exactly the five product artifacts. Its paths include the literal
`artifacts/` prefix, so place those five downloads under an `artifacts` directory before
running a standard checksum verifier, or compare each listed hash to the corresponding
download directly. The two SBOMs, `release-manifest.json`, and `SHA256SUMS` are not listed
inside `SHA256SUMS`; verify them against the GitHub SHA-256 values captured in the
publication attestation and exposed by the GitHub Release API.

All five product artifact hashes agree across the published manifest, `SHA256SUMS`, and
GitHub. All nine downloaded assets agree with their GitHub digests. The uploaded manifest
retains `claims.publicReleaseGo=false`, which was the pre-publication candidate state at
the time it was generated. Because the release was subsequently published, that field is
a historical state erratum; it does not indicate artifact corruption and the published
manifest is not being replaced.

No signing or provenance is claimed. Archive bytes may vary between independent builds;
the reviewed cross-run identity is the normalized Core inventory digest, not absolute
byte-for-byte reproducibility.

## Qualification limits

FSE2 is synthetic-qualified only. The optional local PKCS#12 provider and vertical image
prove synthetic A1 mTLS separation and S1 `contentCommitment`; no real certificate/key
material was imported, no FSE2 OfficialTest call occurred, and `validate-cda` remains
open. There is no FSE2 production or accreditation claim.

Local Administrator and SYSTEM remain residual privileged threats.
`NONDETERMINISTIC_UI_MOCK_20_AXE_SNAPSHOT` remains a documented, non-blocking follow-up;
critical/serious accessibility findings still block the applicable Admin gate.

The golden-path runner performs ownership-checked cleanup in `finally`. If interrupted,
run `./tools/alpha/Invoke-AlphaGoldenPath.ps1 -Phase Stop` from the released source and
confirm that owned project containers, networks, volumes, and synthetic material are
zero. Do not delete unrelated Docker resources or external evidence.
